全能自定义文件夹图标 1.1.0

使用方法
1. 先解压整个压缩包。双击“全能自定义文件夹图标.exe”。
2. 点“选择文件夹”，选中要换图标的那一个文件夹。
3. 点“选择图片”，挑选照片。
4. 点“应用到文件夹”。

也可以把图片和文件夹拖进程序。
默认保留完整图片，自动处理横竖比例、照片方向和图标尺寸。
无需先把图片转成 ICO，也不必手动裁剪。
想自定义裁剪时，点击“自定义裁剪 / 重新框选”，在左侧图片上拖出选区。
拖动框内可移动选区；拖动边角或边中间的小方块可调整大小。
可选“锁定正方形（1:1）”；不勾选时可自由调整长宽。
右侧实时预览最终图标。长方形会等比适配，留透明边，不拉伸。
按 Esc 可取消当前拖动；“重置裁剪”恢复居中正方形。
只有点击“应用到文件夹”才会替换图标。

撤销
选中原文件夹，点“撤销上次替换”。
可逐次撤销本程序做过的替换。以前由其他方式设置的图标也会先备份。
程序旁边的 data 文件夹保存备份，请保留。移动程序时请一并移动 data。
如果图标或 desktop.ini 后来被其他程序改过，撤销会停止，避免覆盖新修改。

说明
这是文件夹的自定义图标，不是修改照片或视频。
图片不被移动、覆盖或删除。只处理选中的单个文件夹，不处理子文件夹。
支持 JPG、JPEG、PNG、BMP、GIF、TIFF、ICO；GIF 使用第一帧。
WebP、AVIF、HEIC/HEIF 等使用 Windows 图片解码器，本机已实测可读。
在其他电脑上，部分格式需要对应的 Windows 图片扩展。
损坏、加密或没有可用解码器的图片会提示原因，不会覆盖原图标。
小图会自动放大，但不能凭空增加细节。横图或竖图留透明边，避免变形。
图标内置 16、24、32、48、64、128、256 像素七种尺寸，Windows 自动选用。
在资源管理器切换“大图标”或“超大图标”，即可看大尺寸效果。
Windows 偶尔会保留旧显示，回到文件夹按 F5 刷新。
无需安装，不要求管理员权限。程序及目标文件夹需要可写。
未运行时没有后台服务，也不加入开机启动。

供自动化调用
以下命令在 PowerShell 中运行；把示例路径换成实际路径。
命令不会打开程序窗口。建议等待进程结束，核对退出码和结果文件。

$p = Start-Process -FilePath '.\全能自定义文件夹图标.exe' -ArgumentList 'apply --folder "D:\示例文件夹" --image "D:\照片.jpg" --result "D:\本次结果.json"' -WindowStyle Hidden -Wait -PassThru
$p.ExitCode

默认 --fit contain，完整显示图片。
填满正方形、居中裁剪可加 --fit cover。
指定裁剪可加：
--crop 120,80,640,480
表示自动校正照片方向后，从 x=120、y=80 开始，截取 640×480 像素。
裁剪结果自动等比放进图标，空余区域透明。
旧格式 --crop 120,80,640 仍可用，表示截取 640×640 像素。
--crop 隐含裁剪模式，不能同时指定 --fit contain。

撤销命令：
undo --folder "D:\示例文件夹"

可选参数：
--backups "自定义备份目录"
--result "新建JSON结果文件"

结果文件必须使用新文件名，并放在目标文件夹之外。
退出码 0 表示完成，1 表示失败；2 表示图标操作完成，但结果输出失败。
失败原因在 JSON 的 Message 中；参数解析失败时会输出到标准错误。
命令行和界面共用备份。指定 --backups 时，撤销也要使用同一路径。
请勿删除图标文件 .folder-portrait.ico 或 desktop.ini，否则图标会失效。
